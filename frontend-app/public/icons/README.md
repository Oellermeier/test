# App Icons

Hier werden die PWA-Icons abgelegt.

Benötigt werden:
- `icon-192.png` — 192×192 px (Home Screen Icon)
- `icon-512.png` — 512×512 px (Splash Screen / Store)

Erstellen z.B. mit:
- https://realfavicongenerator.net/
- https://maskable.app/ (für maskable icons)

Bis Icons vorhanden sind, ist die App funktionsfähig aber nicht vollständig installierbar.
